MSL Trading Journal V10 setup

1. Extract the ZIP.
2. Upload the files and folders inside it to the ROOT of the existing GitHub Pages repository (not the ZIP itself and not an extra nested folder).
3. Commit the changes. GitHub Pages publishes the update at the same address when the Pages branch/path is configured as before.
4. Open the site, refresh it once, and use Settings → Download full backup periodically.
5. Add the website to your Android home screen from the browser menu if you want an app-like PWA shortcut.

No Supabase URL/key, account, login, or SQL setup is needed in V10.

IMPORTANT: Data stored only in Supabase does not move into this local-only version automatically. Export it from V9.2 first if it needs to be retained. Session alarms are most reliable while the app is open; web apps cannot guarantee scheduled notifications when fully closed/suspended.
